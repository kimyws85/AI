# Claude Code 사용법

Claude Code는 터미널에서 대화하듯 코드를 읽고, 수정하고, 명령을 실행해 주는 AI 코딩 도구입니다.

## 1. 시작하기

작업할 폴더로 이동한 뒤 실행합니다.

```bash
cd 내프로젝트
claude
```

실행하면 대화창이 열리고, 하고 싶은 일을 평소 말투로 적으면 됩니다.

## 2. 기본 사용 흐름

1. **요청하기**: "로그인 버튼 색을 파란색으로 바꿔줘"처럼 구체적으로 적습니다.
2. **계획 확인**: Claude가 파일을 읽고 무엇을 할지 설명합니다.
3. **권한 승인**: 파일 수정이나 명령 실행 전에 허용 여부를 묻습니다.
4. **결과 확인**: 변경 내용을 보고, 마음에 들지 않으면 다시 요청합니다.

## 3. 잘 요청하는 방법

- **구체적으로**: "버그 고쳐줘"보다 "로그인 후 화면이 비어 있는 문제를 고쳐줘"가 좋습니다.
- **범위를 알려주기**: 어떤 파일이나 기능인지 말해 주면 빨라집니다.
- **한 번에 하나씩**: 큰 작업은 나눠서 요청하면 결과를 확인하기 쉽습니다.
- **확인 요청하기**: "고친 뒤 실행해서 확인해줘"처럼 검증까지 요청합니다.

## 4. 자주 쓰는 슬래시 명령

| 명령 | 설명 |
|---|---|
| `/help` | 도움말 보기 |
| `/clear` | 대화 내용 비우고 새로 시작 |
| `/init` | 프로젝트 설명 파일(`CLAUDE.md`) 만들기 |
| `/config` | 설정 열기 |

사용 가능한 명령은 버전에 따라 다를 수 있으니 `/help`로 확인하세요.

## 5. CLAUDE.md

프로젝트 폴더에 `CLAUDE.md`를 두면 Claude가 매번 읽고 따릅니다. 코딩 규칙, 자주 쓰는 명령, 지켜야 할 주의사항을 적어 두면 같은 설명을 반복하지 않아도 됩니다.

## 6. 권한과 안전

- 파일 수정과 명령 실행은 기본적으로 승인을 받고 진행합니다.
- 삭제, 푸시처럼 되돌리기 어려운 작업은 꼭 내용을 확인하고 승인하세요.
- 비밀번호나 토큰 같은 민감한 정보는 대화에 붙여넣지 마세요.

## 7. Git과 함께 쓰기

Claude에게 "변경 사항을 커밋해줘", "PR 만들어줘"라고 요청할 수 있습니다. 커밋이나 푸시 전에는 `git status`로 무엇이 바뀌었는지 먼저 확인하는 습관이 좋습니다.

## 8. 유용한 팁

- 작업이 끝나면 `/clear`로 대화를 비워 다음 작업과 섞이지 않게 합니다.
- 결과가 이상하면 이유를 물어보세요. 설명을 듣고 방향을 고칠 수 있습니다.
- 반복되는 작업은 `CLAUDE.md`나 스킬로 정리해 두면 편합니다.
